Instructions & GitHub Pages Hosting
  1. Host these files (manifest.xml, index.html, app.js) on GitHub Pages.
  2. In manifest.xml, replace https://YOUR-GITHUB-USERNAME.github.io/YOUR-REPO-NAME/ with your live URL.
  3. In Word desktop, go to Insert > Add-ins > My Add-ins > Shared Folder (or sideload via Word for Web developer add-ins).
  4. Click the Math Equation button in Word's ribbon to launch this task pane.
